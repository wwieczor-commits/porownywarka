Połączenie z Claude

Aplikacja korzysta z Claude przez API Anthropic. Wklej swój klucz API (zaczyna się od sk-ant-). Klucz zostaje tylko w tej przeglądarce i jest wysyłany wyłącznie do api.anthropic.com. Klucz założysz na platform.claude.com.

Linki trafiają do kolejnych wolnych miejsc. Możesz też po prostu wkleić (Ctrl+V) w dowolnym miejscu strony albo przeciągnąć link. Gdy oba miejsca są pełne, porównanie startuje samo.

Brak połączenia z Claude. Dodaj klucz API (przycisk „Klucz API” na górze), żeby porównywać własne linki. Poniżej widać przykładowe porównanie.

Claude otwiera stronę produktu i czyta z niej cenę i parametry. Część sklepów blokuje automatyczne pobieranie. Wtedy dane pochodzą z wiedzy Claude'a, a cena jest oznaczona jako szacunek. Dokładną cenę dostaniesz, gdy dołączysz zrzut ekranu strony albo wkleisz jej tekst.
